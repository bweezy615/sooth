# Pick engine — margin model + selective publishing

Supersedes Step 0 ("freeze the model layer") of `docs/pick-engine-plan.md`.
That freeze was correct while the product was *timing* (sealed slate sold
early). The paid tier is gone; what is left to sell is the answer itself, so
the decision rule is now in scope.

## What is wrong today

1. **The ATS decision is made by a probability model through a hardcoded
   conversion.** `_ats()` (in both `engine/models/ensemble.py` and
   `scripts/published_figures.py`) turns a win probability into an implied
   margin with `logit(p) * 400/ln(10) / 25.0`. The `/25.0` is an Elo-scale
   constant; the sklearn logistic's logit is on no such scale. Every pick's
   threshold against the spread is therefore shifted by an arbitrary factor.
   The model is also trained on binary `home_won`, which throws away margin —
   the exact quantity the spread is about.

2. **The engine has an opinion on every game.** 2,608 graded games across
   2016-2025 is ~261 a year: one per game, always. Measured 49.79% ATS
   (z = -2.65). Forcing an opinion on every game is the largest single source
   of losing bets.

3. **The published selection rule is worse than no rule.** `divergence_rank`
   orders games *within a week* by |independent_prob - market_prob|. Measured:
   top1 50.2%, top2 50.4%, top3 51.6%, top5 52.3%. A within-slate rank always
   promotes something, even in a week where the model agrees with the market
   everywhere.

## Measured, walk-forward, leakage-controlled (2016-2025)

| rule | ATS% | n |
|---|---|---|
| bet everything (today) | 49.79 | 2608 |
| direct margin model, bet everything | 49.77 | 2608 |
| margin model, abs edge >= 3 | 51.77 | — |
| margin model, abs edge >= 4 | 53.15 | — |
| margin model, abs edge >= 5 | 54.69 | — |
| **abs edge >= 4 AND the play is the underdog** | **54.83** | **383** |
| abs edge >= 5 and underdog | 56.02 | — |

Favourites in the same edge>=4 bucket: 49.7%. The signal is the dog side,
which matches the documented NFL favourite bias.

Holdout discipline: thresholds chosen on 2016-2021, then applied unchanged to
2022-2025 -> 55.0% (n=149).

**None of this is statistically significant.** Best z is +0.96 — roughly a
one-in-six chance of being noise, before accounting for the fact that the cut
was found by searching thresholds. Any published version of these numbers
ships with the interval and with every losing season, or it is the exact thing
`/picks` accuses everyone else of.

## Changes

### Phase 1 — `engine/models/ensemble.py`
- Add `_wf_margin()`: walk-forward `Ridge` predicting `margin` directly.
- Every model gets a real predicted margin: ours from the Ridge on features,
  the market's from a Ridge on `market_logit` alone (the honest, *fitted*
  version of what `/25.0` was guessing at), Elo's from its own
  `expected_margin`.
- `_ats()` takes a margin column. The `/25.0` constant is deleted.
- `selectivity()`: ATS record by absolute-edge threshold, split
  all/underdog/favourite, with Wilson 95% intervals and per-season records.

### Phase 2 — `scripts/published_figures.py`
- Same `_ats` fix (it carries its own copy of the bug).
- New `selectivity` block in `_figures.json` so the threshold is a published
  measurement, not a hand-typed constant. Hard rule of this repo.

### Phase 3 — `engine/pipeline/weekly.py`
- Fit the margin model on full history alongside the two probability models.
- Per game emit `pred_margin`, `ats_edge` (= pred_margin - spread_line, home
  basis), `ats_pick`, `ats_underdog`, `ats_qualified` (|edge| >= 4).
- Rank by |edge| for qualified plays. `divergence_rank` stays — the sealed
  W01 payload, `picks.html` and `test_pickengine_payloads.py` all read it.

### Phase 4 — `site/public/picks.html`
Surface the qualified plays and, when there are none, say so. The existing
`NOPLAY_DIVERGENCE` banner is the hook; it changes from a divergence bar to
the edge bar.

## Not in scope
- Re-sealing `2026-W01-nfl`. Its Merkle root was anchored 2026-08-06 and is
  the flagship `/verify` walkthrough. New fields appear from W02 forward.
- Opponent-adjusting `def_epa_pp` (currently raw). Real gap, separate change.
- Any win-rate claim in marketing copy. Backtest tables on `/methodology`
  only, generated by the script.
